# Map Crafting and Progression

Use the **Horadric Cube on Hell difficulty** to prepare your maps. Upgrade to raise the tier, reroll to change modifiers, or corrupt a Tier 5 map to reach Tier 6.

[Getting started](/en/maps/overview) · [Maps and Wardens](/en/maps/map-list) · [Modifiers](/en/maps/modifiers) · [Encounters](/en/maps/encounters)

## Mapping currencies

| Item | What it does | Where to find it |
| --- | --- | --- |
| **Horadric Orb** | Raises a map by one tier, up to Tier 5. | Map monsters, Wardens, and certain event rewards. |
| **Arcane Relic** | Rerolls a map's modifiers while keeping its theme and tier. | Map monsters, Wardens, and certain event rewards. |
| **Worldstone Shard** | Converts a Tier 5 map into Tier 6. | Mapping-currency drops from map monsters, Wardens, and certain event rewards. It is the rarest of these three currencies. |

You can find Worldstone Shards before reaching Tier 5. Save them until you have a Tier 5 map and are ready for the harder run.

## Cube recipes

Use one of each listed item. The map and currency are consumed to create the result; opening a map consumes the map to create its portal.

| Ingredients | Result |
| --- | --- |
| **1 map by itself** | Opens a portal to that map. Use this in Harrogath on Hell. |
| **1 Tier 1 map + 1 Horadric Orb** | Tier 2 map of the same theme. |
| **1 Tier 2 map + 1 Horadric Orb** | Tier 3 map of the same theme. |
| **1 Tier 3 map + 1 Horadric Orb** | Tier 4 map of the same theme. |
| **1 Tier 4 map + 1 Horadric Orb** | Tier 5 map of the same theme. |
| **1 Tier 5 map + 1 Worldstone Shard** | Tier 6 map of the same theme. |
| **1 map of any tier + 1 Arcane Relic** | A new modifier roll on the same theme and tier, including Tier 6. |

**Read the result after every craft.** Upgrading and corrupting create a new map with a new modifier roll; they do not preserve the old roll. Rerolling is random and does not guarantee easier modifiers or a different combination.

There is no Horadric Orb upgrade from Tier 5 to Tier 6, and there is no tier above Tier 6. Corruption here is the listed Tier 5-to-Tier 6 recipe; it is not a chance to destroy the map.

## Building a supply of maps

Your first Tier 1 maps come from the [late-Hell farming areas](/en/maps/overview#where-do-i-get-my-first-map). Inside maps:

- **Ordinary monsters and elites** can drop mapping currency and maps of the current tier. In Tiers 1–4, they can also drop a map one tier higher.
- **Wardens** reward a map of the current tier and one mapping currency. In Tier 6, the map reward is Tier 5.
- **Tier 5 and Tier 6 map drops** top out at Tier 5. Tier 6 always requires a Worldstone Shard craft.
- **Some encounters** offer additional maps or crafting materials. See [events and treasure monsters](/en/maps/encounters).

Dropped maps can be a different theme from the one you are running. Crafting preserves the theme of your input map.

Clearing the main area gives you more chances at maps and currency; defeating the Warden provides the dependable map reward at the end. You do not have to spend an orb on every step of progression if you find higher-tier maps along the way.

## When should I upgrade or reroll?

**Upgrade when the current tier is comfortable.** Higher tiers have tougher enemies and more modifiers, so rushing upward can cost more than it earns.

**Reroll when a modifier is particularly bad for your build.** Resistance penalties, reduced skills, and dangerous monster auras deserve a second look. An Arcane Relic keeps the map at the same tier, letting you try for a more suitable roll.

**Corrupt when you are ready for Tier 6.** It has four modifiers and a much sharper increase in monster strength. A good Tier 5 clear is preparation, not a guarantee that the next run will be easy.

Craft before opening the map. Rerolling a second item will not reset a map you already visited in the current game; start a new game to repeat that theme and tier.
